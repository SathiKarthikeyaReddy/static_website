## Overview

A fully static, no-framework web project demonstrating clean semantic HTML structure, responsive CSS layout, and vanilla JavaScript interactivity. Great reference for fundamental web development skills.

## Features

- 📱 Fully responsive layout
- 🎨 Clean, modern CSS styling
- ⚡ Zero dependencies — pure vanilla HTML/CSS/JS
- 🔍 Semantic HTML5 structure

## Running Locally

```bash
# Just open index.html in your browser — no build step needed!
git clone https://github.com/SathiKarthikeyaReddy/static_website.git
cd static_website
# Open index.html in your browser
```

Or use Live Server in VS Code for hot reload during development.
